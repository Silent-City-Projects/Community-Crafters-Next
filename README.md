## Development

In order to make changes to this pack, you will need to use the packwiz tool found [here](https://nightly.link/packwiz/packwiz/workflows/go/main)

If you wish to sync a local Prism instance to changes made during development, you can change the unsup.ini file found in the provided Prism instance
to refer to http://localhost:8080/pack.toml, and run `packwiz serve` to run a development web server that automatically refreshes the index.
